# 프로젝트 상세 페이지

## 작업 내역

- 프로젝트 목록·홈 프로젝트 클릭 시 별도 상세 페이지로 이동하도록 변경했습니다.
- 기본 정보·수동 진행률·목표·저장소, 연결 작업·최근 일지 3건과 빈 상태를 표시합니다. 기존 편집·보관·저장 실패·미저장 변경 보호를 재사용합니다.
- 목록 검색·분야·보관 선택 유지, 배치 편집 중 이동 차단, 상세 진입 초점·스크롤과 모바일 긴 텍스트를 처리했습니다.
- 상세 화면·표시 컴포넌트·이동 상태의 책임을 분리하고 기존 API 재사용 요구사항을 ARCHITECTURE.md에 기록했습니다.
- 검증: 빌드, 단위 테스트 10개, 브라우저 테스트 21개, 변경 파일 포맷 통과. 전체 포맷은 기존 미수정 파일 40개 문제로 실패했습니다.

## 추가 사항

- 내부 상태 기반 페이지 전환입니다. 상세 URL·새로고침 위치 복원·브라우저 뒤로가기는 안정화 14번 범위이며, 11·12번은 대기 상태를 유지합니다.
