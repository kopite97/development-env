# 백엔드 API 요구사항 정리

## 작업 내역

- 안정화 1~8번 구현과 기능별 Provider·편집기·검색·통계를 기존 API 문서와 대조했습니다.
- ARCHITECTURE.md에 현재 기능별 API 요약과 후속 기능 방향, 상세 API 문서 연결을 추가했습니다.
- API.md의 오래된 상수·보관 작업 집계·저장 실패·일지 모델 설명을 수정했습니다.
- 태스크 상세·휴지통·복구, 프로젝트 보관 해제·선택 유지, 입력 제한, 검색 total·0건 응답, 재시도·revision·로컬 이전 계약을 보완했습니다.
- 링크·일지 관리, 프로젝트별 위젯, 마일스톤, 백업·가져오기, 초안 복구, 작업 기한·변경 이력·운영 연동의 API와 우선순위를 제안했습니다. 현재 필수 계약과 미구현 제안을 구분했습니다.
- 검증: 변경 문서 Prettier 검사 및 git diff --check 통과. 문서만 변경하여 앱 빌드·테스트는 재실행하지 않았습니다.
