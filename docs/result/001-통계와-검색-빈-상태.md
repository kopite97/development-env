# 7~8번: 통계와 검색 빈 상태

## 작업 내역

- 프로젝트 수를 검색 결과와 분리하고 현재/보관·분야 기준으로 계산했습니다. 작업 수는 분야 전체의 미삭제 작업을 집계하며 보관 프로젝트의 작업도 유지합니다.
- 프로젝트·태스크·개발일지·자료실의 검색 결과 수를 별도로 표시했습니다.
- 공용 EmptyState에 초기화 동작을 추가하고 홈을 포함한 5개 화면에서 검색·분야 초기화 및 기존 생성 버튼을 연결했습니다.
- 빌드 및 단위 테스트 7개, Chromium 브라우저 테스트 14개 통과. 검색 전후 통계·분야·보관 집계, 빈 상태 초기화·생성 창, 기존 CRUD·저장 실패·드래그·모바일 회귀를 확인했습니다.
- 변경 파일 포맷 검사와 git diff --check 통과. 전체 format:check는 기존 미수정 파일의 포맷 문제로 실패했습니다.

## 추가 사항

- 검증용 Playwright Chromium을 설치했습니다. 링크 추가 기능은 기존 계획의 10번 범위입니다.
- 신규 서버 API 요구사항 없음. 기존 로컬 저장 키와 구조를 유지합니다.
