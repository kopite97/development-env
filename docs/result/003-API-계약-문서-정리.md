# API 계약 문서 정리

## 작업 내역

- API.md를 범위, 공통 계약, 홈 배치, 업무 리소스, 통계·연동, 조건부 연동, 후속 제안, 완료 검증 기준으로 재구성했습니다.
- 조회·작성·추가 보완 절에 반복되던 API와 저장·검색·복구 규칙을 통합하고 구현 이력·반복 예시를 제거했습니다.
- 목록 응답, revision, 생성 재시도, 보관·연결 데이터 집계 기준을 한곳에서 정의했습니다. 첨부·외부 연결·Unity·에이전트 확장은 후속 범위로 모았습니다.
- ARCHITECTURE.md의 절 참조와 링크를 갱신했습니다.
- 검증: 변경 문서 Prettier 검사와 git diff --check 통과. 문서만 변경하여 앱 빌드·테스트는 재실행하지 않았습니다.
