# 14번: URL 라우팅과 방문 기록

## 작업 내역

- 메뉴·프로젝트 상세를 URL과 브라우저 방문 기록에 연결했습니다. 직접 접속·새로고침·뒤로가기·앞으로가기에서 같은 화면을 복원합니다.
- 검색·분야·보관 조건을 URL에 보존하고 조건 변경과 같은 화면 클릭으로 불필요한 방문 기록이 쌓이지 않게 했습니다.
- 배치 편집 중 이동 차단, 미저장 폼의 폐기 확인, 이동 취소 시 주소·입력·앞으로가기 기록 유지, 없는 주소·프로젝트의 복귀 화면을 구현했습니다.
- 기존 Nginx SPA fallback을 재사용하고 라우팅 책임·API 불필요 사항을 ARCHITECTURE.md에 기록했습니다.
- 검증: 빌드, 단위 테스트 13개, 브라우저 테스트 26개, 변경 파일 포맷 통과. 전체 포맷 검사는 기존 미수정 파일 38개 문제로 실패했습니다.
