# AGENTS.md

This directory contains technical and architectural decision records.

## Rules

- Record decisions that have meaningful impact on architecture, tooling, conventions, or maintainability.
- Document the context, decision, rationale, and consequences.
- Keep each decision focused on a single topic.
- Do not rewrite historical decisions after they are accepted; add a new decision when replacing or superseding one.
- Use lowercase kebab-case file names.
- Reference related code, plans, or documentation when relevant.
