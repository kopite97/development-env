# AGENTS.md

This directory contains documentation for the current system architecture.

## Rules

- Document the system as it currently exists.
- Describe boundaries, responsibilities, dependencies, and data flow where relevant.
- Keep architecture documentation aligned with the codebase.
- Do not document planned or speculative architecture as current state.
- Prefer diagrams when they improve structural understanding.
- Use lowercase kebab-case file names.
- Reference related decisions and implementation paths when relevant.
