# Plan: Milestones and keyboard accessibility

## Goal

안정화 13번(독립 마일스톤 관리)과 15번(키보드·모달 접근성)을 구현한다.

## Scope

- In scope: 프로젝트별 복수 마일스톤 생성·수정·완료/재개·선택 기한, 홈 위젯과 프로젝트 상세 연동, 로컬 저장 및 편집 보호. 모바일 메뉴 초점 진입/순환/복귀·Escape·배경 비활성화·화면 크기 변경, 모달 이름 및 진행률 이름.
- Out of scope: 서버, 마일스톤 삭제, 태스크 기반 자동 진행률, 16~18번 후속 작업.

## Changes

1. 마일스톤 모델/Provider/편집기/목록을 features/milestones에 둔다. 새 저장 키 `devspace.milestones.v1`를 사용하고 기존 프로젝트 목표는 최초 기본 목록으로 가져오되 임의 기한을 만들지 않는다. 저장된 빈 배열도 보존한다.
2. 홈 위젯은 미완료 목표를 기한순(기한 없음은 뒤)으로 표시하며 프로젝트와 표시 개수 설정을 유지한다. 완료 목록 선택으로 재개할 수 있다. 상세에서는 해당 프로젝트 전체 목표를 관리한다.
3. 메뉴 열기 버튼의 expanded/controls, 메뉴 이름, 내부 닫기 버튼, 초점 순환과 복귀를 추가한다. 모달의 기존 이름과 미저장 변경 보호를 유지하고 진행률에 프로젝트 이름을 연결한다.
4. 검증 성공 후 계획/현재 구조를 갱신하고 이력 파일은 표의 11·12·13·15번 상태만 완료로 변경한다.

## Validation

### Static

- 빌드, 날짜/저장 모델 단위 테스트, 소스 경계 검사, 문서 링크 검사, 변경 파일 포맷 검사.

### Runtime

- 생성·수정·기한·완료/재개 및 홈/상세/새로고침 일관성, 기존 목표 가져오기, 프로젝트/표시 개수 조건.
- 저장 실패/재시도, 미저장 취소/Escape/이동 보호, 빈 목록 및 긴 제목·낮은 모바일 화면.
- 모바일 메뉴의 초점 진입/Tab/Shift+Tab/Escape/닫기/이동/데스크톱 전환, 배경 비활성화와 프로필 모달.
- 이름 있는 모달·진행률과 기존 브라우저 회귀 전체 실행.

## Completion Criteria

- [x] Planned changes are implemented.

- [x] Runtime validation passes when applicable.
- [x] Related documentation is updated if required.

## Authorization

2026-09-10 proposed로 등록한 뒤 사용자의 PLAN 작성 및 즉시 진행 요청에 따라 active로 전환한다.

## Results

- 2026-09-10 완료: 빌드, 단위 테스트 19개, Chromium 브라우저 테스트 35개 통과. 빌드 캐시 쓰기 권한 오류는 승인된 빌드 명령 재실행으로 해결.
- 소스 경계(72개 파일), 문서 링크, 변경 파일 포맷 검사 통과.
- 기존 목표 초기화/빈 저장 목록, 생성·수정·기한 해제·완료/재개, 홈/상세/재로드 연동과 모바일 긴 제목을 검증.
- 저장 실패 시 초안/기존 상태 유지, 재시도, Escape·취소·뒤로가기 거절, beforeunload 보호 검증.
- 모바일 메뉴 초점 순환/복귀, Escape·배경 클릭·메뉴 이동·데스크톱 전환, 프로필 모달 복귀, 편집 모달 초기 초점/Tab 순환, 진행률 이름 검증.
- 공용 모달의 초점 초기화/순환/복귀를 보완했으며 기존 전체 회귀 통과.
- 이력 파일은 사용자 요청대로 표의 11·12·13·15번 상태만 완료로 변경. 나머지 본문은 보존.
