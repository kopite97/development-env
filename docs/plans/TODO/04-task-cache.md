# 04. 할 일 캐시·갱신 범위 개선

진행 상태와 실행 PLAN: [추적 목록](readme.md). 선행: 02, 필요 시 03.

- 목적: 할 일 화면과 홈 위젯에서 조회 결과를 재사용하고 필요한 데이터만 갱신한다.
- 범위: 목록·통계·홈 할 일 위젯, 상태 변경·휴지통·복구 후 갱신.
- 작업: 조건별 캐시 정책과 변경 영향표를 정의하고 과도한 무효화를 줄인다.
- 검증: 필터·페이지·통계 일치, 홈↔할 일 이동, 다른 브라우저 변경의 재확인, 수정 충돌.
- 완료 기준: 이동·변경 후 요청이 감소하고 목록·통계·위젯의 정합성을 유지한다.
- 제외: 일지·마일스톤·링크 일괄 변경, 실시간 알림 도입.

- [01 결과](../../reviews/plan0021-query-baseline/readme.md): 홈·작업 보드 재방문은 이미 0건이다. 단순 이동보다 변경 후 갱신 범위를 우선 검토하며, 아직 측정하지 않은 할 일 변경 흐름을 착수 시 확인한다.
