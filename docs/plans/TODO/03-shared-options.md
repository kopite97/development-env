# 03. 공통 선택 데이터 조회 공유

진행 상태와 실행 PLAN: [추적 목록](readme.md). 선행: 02.

- 목적: 여러 편집 화면의 카테고리·프로젝트 선택 데이터 중복 조회를 줄인다.
- 작업: 동일 조회 조건의 원본 데이터와 진행 중 요청을 공유하고 불필요한 직접 재조회를 정리한다.
- 경계: 활성/전체 프로젝트, 필터·페이지가 다른 요청은 구분한다. 선택된 보관 프로젝트의 개별 조회를 유지한다.
- 검증: 편집창 왕복, 페이지 추가 조회, 프로젝트 이름·상태·분류 변경, 카테고리 변경 반영.
- 완료 기준: 동일 조건 재사용 시 중복 호출이 줄고 선택값·옵션이 정확히 표시된다.
- 제외: 백엔드 선택 API 신설, 전체 프로젝트 선조회.

- [01 결과](../../reviews/plan0021-query-baseline/readme.md): 프로젝트 편집창은 매번 카테고리 1건, 일지 편집창 첫 열기는 프로젝트 1건을 요청했다. 할 일·일지 편집창의 재열기는 이미 0건이므로 유지한다.
