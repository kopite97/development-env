# 05. 홈 최초 진입 요청 흐름 최적화

진행 상태와 실행 PLAN: [추적 목록](readme.md). 선행: 01; 02~04 결과로 우선순위 조정.

- 목적: 캐시가 없는 최초 진입의 데이터 표시 시간을 줄인다.
- 작업: 측정된 요청 의존성을 확인하고 독립 요청 병렬화·불필요한 선행 대기 제거를 적용한다.
- 작업: 바로 표시할 필요가 없는 데이터의 조회 지연을 검토한다. 설정이 필요한 요청의 의존성은 유지한다.
- 검증: 최초 주요 데이터 표시 시간, 전체 로딩 시간, 요청 수·전송량, 위젯별 실패·재시도.
- 완료 기준: 기준 측정 대비 표시 시간이 개선되고 불필요한 선조회 증가가 없다.
- 제외: 새 집계 API, SSR 전환, 모든 데이터 사전 로딩.

- [01 결과](../../reviews/plan0021-query-baseline/readme.md): 최초 진입 API 13건, 주요 표시 중앙값 449.5ms(로컬 10회). 인증→설정→위젯 의존성과 선택 데이터 선조회를 검토하되 서로 다른 필터 요청은 중복으로 취급하지 않는다.
