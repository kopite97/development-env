## 추적 방법

- 이 표를 후보 계획의 상태 기준으로 사용한다: `대기 → 계획 작성 → 진행 중 → 완료`, 필요 시 `보류` 또는 `취소`.
- 착수 전 [계획 지침](../../plans/PLANS.md)에 따라 정식 PLAN을 작성하고 위 표에 상대 링크를 기록한다. 실행 상태는 [정식 목록](../../plans/README.md)과 함께 갱신한다.
- 완료 시 검증 결과 링크와 완료일을 기록한다. 보류·취소 시 아래 이력에 이유를 남긴다.
- 공통 검증: 계정·작업실 격리, 지연 응답 차단, 변경 반영, 실패·재시도, 요청 수·전송량·표시 시간 비교.
- 장기 적용: [조회 정책 지침](../../guides/query-policy.md)에 따라 02에서 공통 생성 경로·검사를 마련하고 03~05는 같은 기반을 사용한다. 미전환 일지·마일스톤·링크 저장소는 별도 계획과 명시적 예외로 추적한다.
- 일지·마일스톤·링크 확대는 02·04의 효과를 확인한 뒤 기능별로 별도 계획한다.
